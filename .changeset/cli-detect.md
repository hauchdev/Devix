Adds the first Devix CLI (`@devix/cli`) with the `devix detect` command: detects the current project's languages, package managers and tools via `@devix/project-detector`, with `--json` and `--cwd` flags. `devix --version` and `devix --help` are available from the `bin/run.js` entry.
