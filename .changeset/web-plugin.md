Add the `web` plugin and `devix web`. Subcommands: `detect` (frameworks and whether they are static), `env` (variable **names** only, never values), `scripts`, `build` and `serve` (both print-first) and `doctor`. Includes a dependency-free, read-only static file server with path-traversal protection.
