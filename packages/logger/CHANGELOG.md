# @devix-cli/logger

## 0.2.0

### Minor Changes

- 95d9967: Deprecate `@devix-cli/logger`. The package is no longer maintained, has no consumers inside Devix, and will be removed in a future release. Use your own logger or the upcoming structured output package instead.

## 0.1.0

### Minor Changes

- First public release: the Devix CLI (`npm i -g devix-cli`) with `status`, `detect`, `doctor`, read-only `git` commands, dependency delegation through the detected package manager, Docker diagnostics with graceful degradation, and the `@devix-cli/*` service packages powering them.
